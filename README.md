# Student Performance - Linear & Logistic Regression

A basic machine learning project on the Kaggle **Students Performance in Exams** dataset (1000 students).

- **Linear Regression** -> predicts the math score (R2 = 0.88, MAE = 4.2 marks)
- **Logistic Regression** -> predicts Pass / Fail in math (pass mark = 60, accuracy = 89.5%)

## What is inside
| File | What it is |
|---|---|
| `Student_Performance_ML_Project.ipynb` | Main notebook (code + outputs + charts) |
| `StudentsPerformance.csv` | Dataset |
| `requirements.txt` | Libraries needed |

## Steps
1. Load data and explore it (head, shape, info, describe)
2. Cleaning - missing values and duplicates (none found)
3. Charts - matplotlib and seaborn (histogram, countplot, boxplot, scatter, bar, heatmap)
4. One-hot encoding + correlation
5. Linear Regression - train/test split, training, MAE / RMSE / R2
6. Logistic Regression - accuracy, confusion matrix, classification report
7. Prediction for a new student + summary

## How to run
Open the notebook in Google Colab (upload the csv in the Files panel) or locally:
```
pip install -r requirements.txt
jupyter notebook Student_Performance_ML_Project.ipynb
```
